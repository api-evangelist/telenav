# Telenav

> Telenav is a connected-car and location-based services company providing in-vehicle navigation (VIVID NAV), infotainment (VIVID IVI), and in-car commerce (VIVID COMMERCE) for automotive partners including Daimler, Ford, GM, Toyota, and Xpeng. Its developer surface centers on the Entity Service REST API — location-aware semantic search, suggestions, entity detail lookup, and discovery (including EV charge-station search) — plus partner-distributed SDKs for navigation and driver intelligence.

Telenav publishes no llms.txt of its own (probed 404 on www.telenav.com and docs.telenav.com); this file was generated from the API Evangelist catalog entry and docs.telenav.com on 2026-07-21.

## APIs

- [Entity Service REST — Overview](https://docs.telenav.com/overview/entity-rest.html): Semantic search, prediction, lookup, and discover services (v5, JSON).
- [Search](https://docs.telenav.com/entity-rest/search.html): Onebox, category/brand filter, corridor, polygon, bbox, reverse geocoding, EV charge-station search (/v5/search/json).
- [Predictions](https://docs.telenav.com/entity-rest/prediction.html): Auto-suggest and word prediction (/v5/prediction/suggestion/json, /v5/prediction/word/json).
- [Lookup](https://docs.telenav.com/entity-rest/lookup.html): Entity detail by ID, batch supported (/v5/detail/json).
- [Discover](https://docs.telenav.com/entity-rest/discover.html): Discover place/brand/category and the POI category tree (/v5/discover/*, /v5/category/json).
- [Common (auth + parameters)](https://docs.telenav.com/entity-rest/common.html): API key + SHA-256 request signature headers (x-tn-api_key, x-tn-api_signature), common headers and parameters.
- [EventHub](https://docs.telenav.com/overview/eventhub.html): Publish-subscribe messaging APIs for the Telenav Cloud.
- [Notification Service](https://docs.telenav.com/overview/notification-service.html): Subscribe to event types with delivery via email or http/https endpoints.
